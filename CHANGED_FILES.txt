Nodus v0.1 — context budget + deterministic analysis flow

Apply this archive over the previous plan-final-result patch.
No nodus.config.json changes are required.

Changed:
- src/agent/Runtime/AgentRuntime.ts
  * plan can no longer execute tools
  * understand: max 2 tool batches, max 3 calls per batch
  * understand -> finalize after budget/no-action
  * blocks understand -> plan bounce
  * finalize forced to terminate instead of looping
- src/agent/Execution/ToolExecutor.ts
  * configurable per-operation batch limit
  * raw toolContext survives for only the immediate next model call
- src/context/Selector/ContextBudget.ts (new)
  * operation-specific context budgets
  * clips raw tool payloads by chars as a tokenizer-free MVP safeguard
- src/context/Selector/ContextSelector.ts
  * applies context budgets to history, file index and tool context
- src/model/Profile/PromptRegistry.ts
  * plan is router-only
  * understand must summarize observations and stop gathering after two rounds
  * new finalize prompt
- src/model/Controller/ModelController.ts
  * plan/finalize do not expose tools to the model
- src/operation/Default/DefaultOperationProfile.ts
  * adds finalize operation

Expected analysis flow:
plan -> understand -> [<=3 reads] -> understand -> [<=3 reads] -> finalize -> completed
Typical calls: 3-5, depending on whether understand needs one or two evidence batches.

Notes:
- Context budget is intentionally implemented in characters for MVP, not tokenizer-specific tokens.
- tsc could not be fully executed in the packaging environment because @types/node/node_modules are not installed there.
