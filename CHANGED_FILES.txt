Nodus context optimization patch

Changed/added files:
- src/core/Execution/Execution.ts
- src/agent/Execution/ToolExecutor.ts (new)
- src/agent/Execution/ChangeExecutor.ts (new)
- src/agent/Runtime/AgentRuntime.ts
- src/context/Context/ModelContext.ts
- src/context/Selector/ContextSelector.ts
- src/model/Controller/ModelController.ts
- src/model/Profile/PromptRegistry.ts
- src/core/Nodus/Nodus.ts

What changed:
- Full tool results no longer go into Execution.history.
- Latest tool results are kept in temporary toolContext.
- toolContext is available for up to two subsequent model calls, then cleared.
- Tool batches are capped at 5 calls.
- Tool logging is summarized by tools-started/tools-finished.
- Tool execution and change application moved out of AgentRuntime.
- plan prompt is constrained to routing instead of producing a final detailed answer.

After overlaying this patch run:
  npx tsc --noEmit
  npm run dev -- nodus.config.json
