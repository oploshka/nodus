Nodus response protocol prototype

Added:
- src/model/Protocol/NodusResponseProtocol.ts
- src/test/NodusProtocolSmoke.ts

Changed:

The protocol is intentionally not switched on for production ModelController yet.
This commit/prototype establishes a shallow, line-based, partially parseable format
and a deterministic fake-data benchmark before replacing JSON operation by operation.

Observability:
- internal semantic phases now receive hierarchical display ids such as 3.1, 3.2, 3.3.1, 3.3.2
- recovery is displayed as 3.R.1 to distinguish it from the main plan

Protocol notes:
- compact markers use one global END marker; sections end at the next marker
- parser preserves completed sections when the tail is truncated
- production ModelController remains on JSON until the protocol benchmark is accepted
