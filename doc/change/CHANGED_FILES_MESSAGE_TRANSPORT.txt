Behavior:
- Nodus still composes task / step / facts / evidence / source as independent logical blocks;
- physical chat transport is configurable separately through model.messageLayout;
- default collapsed-user layout merges consecutive user blocks into one user message after the system message;
- this satisfies strict Jinja chat templates that require role alternation without inserting fake assistant turns;
- layered layout remains available for backends that support repeated user roles;
- payload logging from ModelController now sees the same collapsed message layout that is sent to the adapter.
