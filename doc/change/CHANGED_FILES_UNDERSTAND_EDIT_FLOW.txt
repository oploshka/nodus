Nodus v0.1 — understand/edit-file flow simplification

Changed:
- src/agent/Planning/PlanExecutor.ts
  - removed the normal pre-step semantic-satisfaction call from the execution loop
  - understand tool rounds now record compact evidence and immediately return raw tool context to the next understand model call
  - normal understand path no longer invokes separate semantic/evidence evaluators
  - understand tool batches are capped at 3 calls
  - edit-file tool requests are not executed; edit-file is a tool-free operation after target preload
  - removed obsolete edit-file duplicate-tool signature tracking
  - recovery-branch pruning now uses exact output postconditions only; no semantic LLM pruning pass

- src/model/Controller/ModelController.ts
  - edit-file no longer advertises available tools
  - edit-file receives a dedicated instruction to edit the supplied authoritative target source immediately
  - runtime-preloaded target source is passed as explicit transient source context

- src/model/Prompt/ModelInputComposer.ts
  - target source reads can be labeled as authoritative edit target content

- src/model/Protocol/EditFileRawProtocol.ts
  - removed the advertised tool-call branch from edit-file instructions
  - protocol now states that the complete target source is preloaded

- src/operation/Default/DefaultOperationProfile.ts
  - edit-file explicitly forbids tools / rereads

- src/context/Selector/ContextBudget.ts
  - edit-file context is focused on one target source and does not carry the project file list/history
  - target-source budget increased so normal source files are not clipped by the generic 12k tool-context limit

Tests updated:
- src/test/UnderstandDerivationSmoke.ts
- src/test/StepEvidenceEvaluatorSmoke.ts
- src/test/ToolEvidenceAccumulationSmoke.ts
- src/test/EditFileTargetContextSmoke.ts
- src/test/ModelInputMessagesSmoke.ts
- src/test/PlanSemanticSatisfactionSmoke.ts

Intended runtime flow:
UNDERSTAND: model -> optional read(s) -> same understand model -> result
EDIT-FILE: runtime preload target -> model -> complete RAW edit
