# Тесты с реальной моделью

Тесты этой группы используют модель из `nodus.config.json` (или из пути `NODUS_TEST_CONFIG`). Они не входят в обычный `npm test`.

## Data-driven сценарии

Эталонные данные сценария лежат в `test/model/scenario/*.schema.ts`. Схема описывает:

- канонический план;
- правильное состояние перед изолированным шагом;
- ожидаемые outputs каждого шага;
- обязательные и запрещённые части значений;
- ожидания по deterministic/model/tool вызовам;
- ожидаемый diff для edit-stage.

Общая логика находится в `test/model/support`:

```ts
await testStep(statusModelScenario, 5);
await testChain(statusModelScenario, 1, 5);
```

`testStep` проверяет шаг на эталонном входе. `testChain` реально выполняет цепочку и сверяет итоговое состояние с теми же ожиданиями. Таким образом один набор данных используется и для изоляции ошибки, и для проверки влияния предыдущих шагов.

Тесты edit-stage перехватывают предложенные изменения и не записывают их в production-файлы.
