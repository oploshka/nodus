# Mock Todo List

Небольшой disposable TypeScript-проект для ручных прогонов Nodus. Он намеренно отделён от исходников самого Nodus, чтобы эксперименты с Worker/Edit не меняли runtime проекта.

Проект содержит простой in-memory todo list: создание задач, просмотр списка и завершение задачи. Зависимости и структура специально небольшие, но достаточные для однофайловых, многофайловых и documentation/config экспериментов.

## Быстрые задачи для экспериментов

- Добавить `priority: 'low' | 'normal' | 'high'` с default `normal` и показывать priority в formatter.
- Добавить `remove(id)` в store/service и тесты для удаления существующей и отсутствующей задачи.
- Добавить фильтр `list(status?: TodoStatus)` без изменения поведения вызова `list()` без аргумента.
- Ограничить длину title до 80 символов и покрыть это тестом.
- Добавить `updatedAt`, которое меняется при completion.
- Обновить README примером использования API без изменения runtime-кода.

Для повторяемых экспериментов после прогона проще всего откатить только эту директорию или распаковать чистую копию заново.
