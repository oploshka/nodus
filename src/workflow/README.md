# Workflow skeleton

Новый каркас Nodus строится вокруг независимых сущностей:

`Workflow -> Stage -> Operation`

Это отношение композиции во время исполнения, а не владение объектами.

- **Workflow** описывает граф ссылок на Stage.
- **Stage** задаёт смысловую фазу и выбирает подходящую Operation.
- **Operation** является исполняемой capability с контрактом inputs/outputs.
- **Artifact** — типизированные данные между операциями и стадиями.
- **Execution / Step / Attempt** описывают конкретный runtime-запуск.

`Stage` не содержит `Operation[]`, `Workflow` не содержит экземпляры `Stage`.
Связи разрешаются через registry/runtime. Старый `PlanExecutor` пока не заменяется:
этот каталог — параллельный архитектурный каркас для постепенного переноса поведения.
