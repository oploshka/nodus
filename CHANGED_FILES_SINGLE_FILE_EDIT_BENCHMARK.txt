Single-file edit protocol benchmark
===================================

Added:
- src/test/EditFileProtocolSmoke.ts
- src/test/EditFileProtocolModelBenchmark.ts

Changed:
- package.json

Purpose:
- Keep edit-file benchmark contract at one model response per file.
- Compare minified JSON full-file output against STATUS/PATH + raw TypeScript to EOF.
- Stress JSON with quotes, backslashes, regexes, template strings and embedded JSON.
- Aggregate multiple independent file edits to model a multi-file task without a multi-file response protocol.

Commands:
- npm run test:protocol:edit
- npm run test:protocol:edit:model -- nodus.config.json compare 1536 1
- npm run test:protocol:edit:model -- nodus.config.json compare 1024 2
